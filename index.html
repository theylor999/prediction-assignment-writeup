1. Overview

Accelerometers on the belt, forearm, arm and dumbbell of 6 participants recorded barbell lifts performed correctly (class A) and incorrectly in four ways (classes B–E) — Velloso, Bulling, Gellersen, Ugulino & Fuks, Qualitative Activity Recognition of Weight Lifting Exercises (Weight Lifting Exercise Dataset, PUC-Rio HAR project). The goal is to predict classe from sensor data and to predict 20 unseen test cases.

Implementation note: the pipeline was run in Python (pandas / scikit-learn) because R was not available on the authoring machine; the report emulates an R Markdown knitr output, and the full code is in analysis.py in the repository. The method (random forest + k-fold cross validation) is identical to what caret::train(method="rf") would do.

The training set has 19,622 rows x 160 columns; the test set has 20 rows. 100 columns are more than 95% missing (summary statistics such as kurtosis, skewness, max, min, avg, var, stddev that are only filled on window-summary rows); they were removed. Identifier / time variables (row index, user name, timestamps, window counters) were also removed so the model learns from sensor movement only and not from the order of the recordings. This leaves 52 numeric predictors. The classes are fairly balanced, with class A the most frequent (Figure 1).

3. Model building and cross validation

The training data were split 70% / 30% (stratified by class, seed 1234) into a training set (13,735 rows) and a hold-out validation set (5,887 rows) that is never used for model fitting or selection. On the 70% part I used stratified 5-fold cross validation to compare three candidate algorithms:

Figure 2. 5-fold cross-validated accuracy of the three candidate models.

Why random forest? It had by far the best cross-validated accuracy, copes with many correlated predictors without scaling, needs no manual feature selection, and gives variable importance. A single tree is fast but less accurate; boosting was better than a tree but still below the forest. Tuning was kept simple (300 trees for validation, 500 trees for the final model, default mtry = floor(sqrt(52)) = 7).

4. Out-of-sample error

The random forest fitted on the 70% training part was applied once to the 30% hold-out set. Hold-out accuracy = 0.9935, so the estimated out-of-sample error is about 0.65%. The 5-fold cross-validated error (0.65%) agrees with it, and the out-of-bag error of the final 500-tree forest fitted on all the data is 0.27%. I therefore expect an out-of-sample error of roughly 0.3–0.7% for new rows from the same six participants.

Caveat: rows from the same participant and the same repetition window are very similar, so random folds are somewhat optimistic. On truly new participants the error would likely be higher. For the 20 quiz cases (which come from the same six participants) this is not a concern.

6. Conclusion

After removing mostly-empty and identifier columns, a random forest on 52 sensor variables classifies the five lifting styles with about 99.4% hold-out accuracy (expected out-of-sample error under 1%), and predicts all 20 quiz cases. Cross validation was used to choose the algorithm and a never-touched hold-out set to estimate the error.
